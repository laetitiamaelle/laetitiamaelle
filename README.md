### 🚀 Projets

**[FixBug]([lien-vers-le-repo](https://github.com/laetitiamaelle/fixbug))**
Plateforme de gestion de bugs full-stack : backend NestJS + PostgreSQL/Prisma, frontend Next.js avec un espace de travail développeur (WebContainer, Monaco Editor, xterm.js), agent IA via OpenRouter ,gemini,grok,mistral.

**[navigateur-ia]([lien-vers-le-repo](https://github.com/laetitiamaelle/navigateur-ia))**
Application Next.js où l'IA (Gemini) interprète des instructions en langage naturel pour exécuter des actions dans le navigateur — système d'onglets, affichage iframe.

**[Votify]([lien-vers-le-repo](https://github.com/laetitiamaelle/votify_frontend))**
Plateforme de vote électronique déployée en production (Django REST Framework + Angular 21). Frontend complet à trois rôles (électeur, administrateur, super-administrateur), auth JWT, navigation par signals.
